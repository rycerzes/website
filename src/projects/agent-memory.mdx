a memory layer for agents that queries a vector store (chromadb) and a knowledge graph (neo4j) in parallel and merges the results. it handles semantic, episodic and procedural memory. an llm decides whether new information adds to, updates or contradicts what's stored, and every change is logged in postgres so the history can be audited.
