a remote mcp server that lets an ai assistant work across gmail, drive, calendar, sheets, slides and tasks, with 50+ tools behind oauth 2.1 and per-user sessions. it also has a graph-backed memory and a sequential-thinking toolset. built with next.js, better auth and vercel's mcp sdk.
