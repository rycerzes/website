a uni semester project to understand how language models work by building every part from scratch: tokenization, a gpt-2 model plus variants with grouped-query, multi-head latent and sliding-window attention, pretraining, then finetuning for classification and instruction following. it stays compatible with gpt-2 weights, so the result can be loaded and chatted with through a small chainlit ui.
