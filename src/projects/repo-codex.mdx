ingests a repository, builds a searchable index over it, answers questions about the code with streaming responses, and generates wiki-style documentation pages.

code is chunked along the syntax tree with tree-sitter, and retrieval mixes semantic vectors with bm25 keyword ranking. ingestion runs as tracked jobs with retry and cancellation. built with tanstack start, postgres + drizzle and bullmq.
